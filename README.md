
# 🎧 TaleTunes – Frontend

TaleTunes is an AI-powered storytelling platform that enhances narration with **background sound effects** and **text-to-speech (TTS)** to create immersive audio experiences. This repository contains the frontend of the application, built for a smooth and engaging user experience.

---

## 🚀 Features

* 🎙️ Text-to-Speech conversion for storytelling
* 🎵 Dynamic background sound effect generation
* 🌐 Multilingual support (if implemented)
* ⚡ Real-time audio playback
* 🎨 Clean and responsive UI
* 🔐 User authentication (if connected to backend)

---

## 🛠️ Tech Stack

* **Framework:** React Native (Expo)
* **Styling:** NativeWind (Tailwind CSS)
* **State Management:** Context API / Redux (if used)
* **API Integration:** REST APIs
* **Audio Handling:** Expo AV / Web Audio APIs

---






## 🎯 Use Case

TaleTunes transforms plain text stories into **cinematic audio experiences** by combining:

* Voice narration (TTS)
* Ambient background sounds
* Emotion-based audio layering
